# 여행상품 추천 웹사이트 · 자료 기반 재구현

2026년 1학기 개인 프로젝트의 기술보고서·재구현 가이드에 제시된 엔티티와 기능 흐름을 바탕으로, 2026-10-28에 작성한 포트폴리오용 재구현입니다. 당시 원본 소스 복구본이 아닙니다. AI 도구를 활용했습니다.

## 실행

Java 17 이상과 Maven이 필요합니다. 이번 검증 환경은 Java 17입니다.

```bash
mvn package
java -jar target/travel-reconstruction-1.0.0.jar
```

http://127.0.0.1:8080 에 접속해 회원가입합니다. 기본 H2 DB와 가상 상품 200개를 자동 생성합니다. 실제 판매 상품이나 결제는 없습니다. 예시 일정은 실행 시점 이후로 생성합니다.

`GEMINI_API_KEY`를 환경변수에 설정하면 후보 상품을 Gemini에 전달합니다. 키가 없거나 응답 검증에 실패하면 규칙 기반 추천임을 화면에 표시합니다. `GEMINI_MODEL`로 모델을 변경할 수 있습니다. 기본값은 `gemini-2.5-flash`입니다.

MySQL 사용 시 `DB_URL`, `DB_USER`, `DB_PASSWORD`를 설정하고 `--spring.profiles.active=mysql`로 실행합니다. MySQL 연결은 이번 환경에서 검증하지 않았습니다.

관리자 테스트가 필요하면 최초 실행 전에 `ADMIN_PASSWORD`를 12자 이상으로 설정합니다. 기본 관리자 비밀번호는 제공하지 않습니다.

## 구현 범위

- 회원가입·로그인·로그아웃, 일반 사용자와 관리자 권한 구분
- 상품 조회, 예산·국가·제외 단어·여행 스타일을 이용한 후보 최대 20개 선정
- 후보 안에서 Gemini 추천 최대 3개와 이유 표시, 외부 응답 실패 시 대체 추천
- 예약·취소·본인 기록 조회, 관리자 상품 등록 및 예약 조회
- 예약 좌석 갱신 시 DB 잠금, 취소 시 소유자 확인

## 원자료와 재구현의 차이

| 항목 | 보고서·가이드 | 이번 재구현 |
|---|---|---|
| 환경 | Java 21, Spring Boot 3.5.14, MySQL | Java 17 호환, Spring Boot 3.5.14, 기본 H2 + MySQL 프로필 |

| 코드 | 보고서 표의 일부 코드와 가이드 | 엔티티 구조 참고, 서비스·컨트롤러·화면 등 완성 |

## 검증 기록 · 2026-10-28

Maven 패키징 성공. H2 임시 DB에서 실제 HTTP 요청으로 홈 화면, 회원가입, 로그인, 추천 3개 표시, CSRF 거부, 일반 사용자 관리자 접근 거부, 예약 생성·취소·목록 반영 등 10개 확인 항목을 통과했습니다.

실제 Gemini 응답, MySQL, 다중 사용자 부하와 좌석 경쟁 상황은 검증하지 않았습니다. 추천 개수 200→20→3은 설정값이며 성능 지표가 아닙니다. 로컬 학습용이며 운영 배포용 인증·속도 제한·감사 체계를 모두 갖춘 서비스는 아닙니다.

검증 스크립트: 새 DB로 서버를 실행한 뒤 `pip install requests` 및 `python verify_http.py`를 실행합니다. 테스트 전용 계정·예약을 생성하므로 개인 데이터가 없는 로컬 환경에서만 실행하세요.

## 환경변수 예시

`.env.example`은 설정 항목 안내이며 자동으로 읽지 않습니다. 실행 전에 터미널 환경변수로 설정하세요. `GEMINI_API_KEY`가 비어 있거나 `your_api_key_here`이면 실제 호출 없이 대체 동작을 사용합니다. 실제 키와 사용자 DB는 저장소에 포함하지 않습니다.
